# GIFT-64 一体化差分分析与验证系统

## 项目简介
本项目是针对轻量级分组密码 GIFT-64 的自动化差分分析与物理验证工程。实现了针对轻量级分组密码 GIFT-64基于SAT的一体化差分分析。在自动化模型中引入标签机制，将差分概率与等效密钥猜测量纳入同一约束框架，实现了对搜索 空间的全局联合寻优，规避了传统搜索易陷入局部最优的陷阱

## 文件说明

### 1. gift.py—— 自动化搜寻引擎
该文件负责生成一体化 SAT 模型并输出攻击图纸。模型引入细粒度的 $v$ 标签追踪时间复杂度（密钥猜测量），同时引入 p, q, m 变量刻画空间复杂度（差分概率），将两者置于同一约束框架下。通过外层 `while` 循环动态放宽概率下界，自动调用 `CaDiCaL` 求解器寻找兼顾时间与数据复杂度的全局最优解。

### 2. 矩阵生成.py —— 底层约束编译器
该文件负责将密码学的数学属性翻译成 SAT 求解器的底层约束。程序根据 GIFT-64 S 盒的差分分布表（DDT），结合 p, q, m 概率变量生成真值表，并通过逻辑最小化算法进行布尔化简，最终生成覆盖 S 盒所有合法状态的最简 CNF 约束矩阵。

### 3. attack.c —— 靶场
该文件负责在算力限制下验证理论图纸的物理可行性。引擎采用纯 C 语言编写，引入查表法（LUT）和位级重构解决端序冲突并实现极速加解密。数据层部署掩码（Mask）预筛剔除噪声；攻击层采用启发式早期剪枝（Early-Abort）截断无效分支；
## 环境要求
* **Python 端**：Python 3.x 环境，并配置外部 SAT 求解器（CaDiCaL），需要在Linux上运行。
* **C 语言端**：支持 C 标准的编译器。
